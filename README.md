# snowfall-css

Чистый CSS-снегопад для любого сайта. Без JavaScript, без HTML-разметки — только подключение стилей. Каждый слой — отдельный файл, количество слоёв регулируется количеством `@import`.

## Демо

Подключите любой из четырёх слоёв к своей странице и увидите снегопад. Слои различаются размером снежинок, скоростью и прозрачностью, поэтому их можно комбинировать для эффекта глубины.

| Файл | Размер снежинок | Скорость | Назначение |
|------|----------------|----------|------------|
| `layer-1.css` | крупные | 8 s | передний план |
| `layer-2.css` | средние | 12 s | средний план |
| `layer-3.css` | мелкие быстрые | 6 s | средний план |
| `layer-4.css` | очень мелкие | 16 s | дальний план |

## Возможности

- **Чистый CSS** — никакого JavaScript и HTML.
- **GPU-анимация** — двигается `transform: translate3d`, а не `background-position`, поэтому не нагружает страницу.
- **Бесшовный цикл** — снежинки распределены по всей высоте экрана, никаких «горстей» и диагоналей.
- **Модульность** — 1 слой = 1 файл. Хотите два слоя — подключаете два файла.
- **Уважает `prefers-reduced-motion`** — при системной настройке «уменьшить движение» анимация отключается.
- **Не перехватывает клики** — у всех слоёв `pointer-events: none`.

## Быстрый старт

Добавьте в свой CSS-файл одну или несколько строк `@import` в самом верху файла:

```css
/* Слой 1 — крупные снежинки (передний план) */
@import url("https://cdn.jsdelivr.net/gh/exdeon/snowfall-css@main/layer-1.css");

/* Слой 2 — средние снежинки */
@import url("https://cdn.jsdelivr.net/gh/exdeon/snowfall-css@main/layer-2.css");

/* Слой 3 — мелкие быстрые снежинки */
@import url("https://cdn.jsdelivr.net/gh/exdeon/snowfall-css@main/layer-3.css");

/* Слой 4 — очень мелкие снежинки (дальний план) */
@import url("https://cdn.jsdelivr.net/gh/exdeon/snowfall-css@main/layer-4.css");
